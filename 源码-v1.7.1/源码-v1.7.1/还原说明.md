## 四、怎么构建

本机验证过的组合：

| 组件 | 版本 |
|---|---|
| JDK | `D:\Java22`（Java 22） |
| Gradle | 8.11.1（本机 `~/.gradle/wrapper/dists` 已被清空，需重新下载或用自己的 Gradle） |
| AGP | 8.5.2 |
| Kotlin | 1.9.22 |
| compileSdk / targetSdk / minSdk | 34 / 34 / 24 |

命令（路径里有中文会构建失败，建议先复制到纯英文路径再编译）：

```bash
cd /d/tmp/aufe_build        # 或任意 ASCII 路径
JAVA_HOME=/d/Java22 <gradle>/bin/gradle assembleRelease
```

签名：

```bash
zipalign -f -p 4 app-release-unsigned.apk aligned.apk
apksigner sign --ks aufe-release.jks --ks-key-alias aufe \
  --ks-pass pass:<口令> --key-pass pass:<口令> \
  --v1-signing-enabled true --v2-signing-enabled true --v3-signing-enabled true \
  --out 安财校园通-v1.7.1.apk aligned.apk
```
